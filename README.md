Deep-Learning-Enabled Efficient Screening for Stable Ga-68 Chelators

When the repository has been cloned, users can run the scripts. The scripts are:
1. pair_num_analysis: Graph Isomorphic Neural Network (GIN) for Coordination Number Prediction
  This repository contains code for predicting coordination numbers using Graph Isomorphic Neural Networks (GIN), predicting relative bond lengths using D-BERT, and implementing data processing techniques along with virtual ligand generation. The methods are applied for radioactive nuclide chelating ligands.
2. bl_analysis: D-BERT for Relative Bond Length Prediction
  This section employs a D-BERT model to predict the relative bond lengths in molecular complexes. D-BERT is a transformer-based model.
3. data_mining and virtual_chelator: Data Processing and Virtual Chelator Generation
